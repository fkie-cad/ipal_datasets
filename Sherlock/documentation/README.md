The documentation to Sherlock is available at [https://sherlock.wattson.it/](https://sherlock.wattson.it/).

Sherlock bases on the [WATTSON](https://wattson.it/) research testbed [1].

The original dataset is published at [https://zenodo.org/records/15168928](https://zenodo.org/records/15168928).

The raw network data of the IEC 60870-5-104 traffic is available at Zenodo [https://zenodo.org/records/15168928](https://zenodo.org/records/15168928).

[1] Lennart Bader et al., "Comprehensively Analyzing the Impact of Cyberattacks on Power Grids," Proceedings of the 8th European Symposium on Security and Privacy (EuroS&P), 2023

[2] Eric Wagner et al., "Sherlock: A Dataset for Process-aware Intrusion Detection Research on Power Grid Networks," Proceedings of the 15th ACM Conference on Data and Application Security and Privacy (CODASPY), 2025
